# 青页 · My Reading Garden

一个简约、清新浅绿风格的个人阅读记录网页。使用原生 HTML、CSS 与 JavaScript，无需安装依赖。

## 使用

下载项目后，在浏览器中打开 `index.html`。
首次打开提供示例内容，可点击「清空示例，开始我的记录」。

## 功能

- 书单：计划读、在读、已读；按书名、作者搜索。
- 书评：记录阅读感想、评分和日期。
- 版本：用书名或 ISBN 跳转豆瓣搜索，手动粘贴选定版本的链接，记录出版社、译者等备注。
- 封面：上传 JPG、PNG 或 WebP，本机压缩后保存在阅读记录中。
- 年终报告：按已读书籍的完成日期统计。
- 阅读热力图：按书籍记录的日期统计，计划读不计入。
- 文学地图：真实国家轮廓、分级着色、国家排行、书目详情，以及世界／欧洲／东亚视角。
- 导出 JSON 阅读记录备份。

## 数据保存

阅读记录与上传封面保存在当前浏览器的本地存储中，不会自动上传 GitHub 或任何服务器。不同浏览器、不同访问地址的数据互不共享；清理浏览器数据会丢失记录，请定期导出备份。

地图按手动填写的作者主要国家／地区统计，故事地点单独保存，不自动推测国籍。热力图每本书目前仅记录一个日期，不是每日阅读计时器。

豆瓣关联使用外部搜索与手动粘贴链接，不提供账号同步、自动获取封面或批量导入。

## 项目文件

- `index.html`：页面与编辑窗口
- `app.js`：阅读记录与统计
- `style.css`：基础样式
- `book-cover.js`：本地封面与版本搜索
- `literary-map.js`、`literary-map.css`：文学地图
- `vendor/`：离线地图数据与 D3

## 第三方数据与许可

- [Natural Earth](https://www.naturalearthdata.com/about/terms-of-use/)：公开领域的 1:110m 国家边界数据，用于阅读分布可视化。
- [D3](https://d3js.org/) 7.9.0：ISC 许可，见 `vendor/D3-LICENSE.txt`。

本仓库提供网页源码；将代码推送 GitHub 不会自动开通在线网站。

## 阅读体验更新

书单改为横向封面与信息条目，可显示作者、可选译者、日期、评分与已有感想。支持全部年份、具体年份、日期未填写，以及日期、评分、书名排序；可搜索书名、作者、译者、ISBN。
国家列表可用名称或代码搜索。移除故事地点相关表单与展示，旧数据仍兼容保存。年终报告改为年度偏爱、初识作者、译者、首末书籍与感想回顾，统计仅限对应年份的已读记录。
